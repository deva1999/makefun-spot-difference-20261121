Spot the difference across three hand-drawn scenes — harbour at dusk, night market, secret garden — 7 hidden differences per round, a countdown, hints, and a score that rewards fast, accurate finds.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network, plain static files under `game/`.
